# Git Demo

The following workflow was demonstrated in the Git demo session. All of these steps are required and marked in the team projects.

1. Dev1 creates a branch and pushes work
2. Dev1 opens a pull request
3. Dev2 is mid-work and needs to look at Dev1's branch so Dev2 stashes work
4. Dev2 checks out Dev1's branch and reviews/comments the code
5. After a communication between several teammates, the PR is approved and merged into the main branch
6. Dev2 goes back to his/her own work
7. Dev2 opens a PR, but there's a conflict
8. Dev2 resolves the conflict and commits the changes
9. PR is discussed and approved, then merged into the main branch
